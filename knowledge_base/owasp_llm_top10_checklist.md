# OWASP Top 10 for LLM Applications - 安全审计检查清单

## 概述

基于 [OWASP Top 10 for Large Language Model Applications](https://github.com/OWASP/www-project-top-10-for-large-language-model-applications) 的官方文档，提取核心检查清单。

---

## LLM01: 提示注入 (Prompt Injection)

### 描述

攻击者通过精心构造的输入，操纵 LLM 执行非预期行为。包括直接注入和间接注入。

### 检查项

#### 1. 输入验证与净化

- [ ] 所有用户输入是否经过验证和净化
- [ ] 是否使用分隔符区分用户内容和系统指令
- [ ] 是否对特殊字符和标记进行转义
- [ ] 是否实施输入长度限制

#### 2. 系统提示保护

- [ ] 系统提示是否包含明确的防护声明
- [ ] 是否有机制防止系统提示被用户输入覆盖
- [ ] 是否使用角色分离（用户/助手/系统）
- [ ] 是否定期轮换或更新系统提示

#### 3. 上下文窗口安全

- [ ] 是否监控上下文窗口中的恶意内容
- [ ] 是否有机制清理或隔离恶意上下文
- [ ] 是否限制上下文窗口的长度
- [ ] 是否有定期注入防护提醒

#### 4. 工具调用安全

- [ ] 工具描述是否被审计以防止工具投毒
- [ ] 是否有机制防止 LLM 执行危险工具
- [ ] 工具调用是否需要人工确认
- [ ] 是否有工具调用的速率限制

---

## LLM02: 不安全的输出处理 (Insecure Output Handling)

### 描述

LLM 生成的输出未经充分验证直接传递给下游组件，可能导致 XSS、CSRF、SQL 注入、命令注入等问题。

### 检查项

#### 1. 输出验证

- [ ] LLM 输出是否经过验证和净化
- [ ] 是否使用白名单过滤输出内容
- [ ] 是否对 HTML、JavaScript 等内容进行转义
- [ ] 是否有输出内容类型检查

#### 2. 下游组件安全

- [ ] 传递给浏览器的内容是否经过转义
- [ ] 传递给数据库的查询是否使用参数化
- [ ] 传递给系统命令的输入是否经过净化
- [ ] 传递给其他服务的消息是否经过验证

#### 3. 内容过滤

- [ ] 是否有有害内容检测机制
- [ ] 是否有敏感信息泄露检测
- [ ] 是否有 PII 数据脱敏
- [ ] 是否有输出日志审计

---

## LLM03: 训练数据投毒 (Training Data Poisoning)

### 描述

训练数据被篡改或注入恶意内容，导致模型产生不安全行为。

### 检查项

#### 1. 数据来源验证

- [ ] 训练数据来源是否可追溯
- [ ] 是否有数据质量检查机制
- [ ] 是否有数据完整性验证
- [ ] 是否有数据清洗流程

#### 2. 模型监控

- [ ] 是否有模型行为监控机制
- [ ] 是否有异常输出检测
- [ ] 是否有定期模型审计
- [ ] 是否有模型回滚机制

---

## LLM04: 模型拒绝服务 (Model Denial of Service)

### 描述

攻击者通过资源密集型操作导致模型服务不可用。

### 检查项

#### 1. 资源限制

- [ ] 是否有输入长度限制
- [ ] 是否有请求速率限制
- [ ] 是否有并发请求限制
- [ ] 是否有超时处理机制

#### 2. 成本控制

- [ ] 是否有 Token 使用量监控
- [ ] 是否有成本预算控制
- [ ] 是否有异常使用检测
- [ ] 是否有自动限流机制

---

## LLM05: 供应链漏洞 (Supply Chain Vulnerabilities)

### 描述

依赖的第三方组件、模型或数据源存在安全问题。

### 检查项

#### 1. 依赖管理

- [ ] 是否审计所有第三方依赖
- [ ] 是否有依赖版本锁定
- [ ] 是否有依赖安全更新流程
- [ ] 是否有供应商安全评估

#### 2. 模型来源

- [ ] 模型来源是否可追溯
- [ ] 模型是否经过安全测试
- [ ] 模型是否有完整性校验
- [ ] 模型是否有定期更新

---

## LLM06: 敏感信息泄露 (Sensitive Information Disclosure)

### 描述

LLM 在交互过程中可能泄露训练数据中的敏感信息。

### 检查项

#### 1. 数据保护

- [ ] 训练数据是否包含敏感信息
- [ ] 是否有数据脱敏机制
- [ ] 是否有输出内容过滤
- [ ] 是否有数据访问控制

#### 2. 隐私控制

- [ ] 是否有 PII 检测机制
- [ ] 是否有数据分类分级
- [ ] 是否有数据访问审计
- [ ] 是否有数据生命周期管理

---

## LLM07: 不安全的插件设计 (Insecure Plugin Design)

### 描述

LLM 插件（如 MCP Server、工具等）存在安全设计缺陷。

### 检查项

#### 1. 插件权限

- [ ] 插件是否有最小权限原则
- [ ] 是否有插件沙箱隔离
- [ ] 是否有插件签名验证
- [ ] 是否有插件审计日志

#### 2. 工具调用

- [ ] 工具调用是否需要确认
- [ ] 是否有工具调用速率限制
- [ ] 是否有工具输入验证
- [ ] 是否有工具输出过滤

---

## LLM08: 过度代理 (Excessive Agency)

### 描述

LLM 被授予过多的权限或自主决策能力，可能导致不安全行为。

### 检查项

#### 1. 权限控制

- [ ] LLM 是否有明确的权限边界
- [ ] 是否有权限最小化原则
- [ ] 是否有权限审计机制
- [ ] 是否有权限撤销机制

#### 2. 决策限制

- [ ] LLM 是否有决策范围限制
- [ ] 是否有重大决策人工确认
- [ ] 是否有决策日志审计
- [ ] 是否有决策回滚机制

---

## LLM09: 过度依赖 (Overreliance)

### 描述

过度依赖 LLM 的输出，未进行充分的人工验证。

### 检查项

#### 1. 人工审核

- [ ] 关键决策是否有人工审核
- [ ] 是否有输出验证机制
- [ ] 是否有错误处理流程
- [ ] 是否有回退机制

#### 2. 监控机制

- [ ] 是否有异常输出检测
- [ ] 是否有性能指标监控
- [ ] 是否有用户反馈机制
- [ ] 是否有定期评估

---

## LLM10: 模型窃取 (Model Theft)

### 描述

攻击者通过特定技术窃取或复制模型。

### 检查项

#### 1. 模型保护

- [ ] 模型是否加密存储
- [ ] 是否有访问控制
- [ ] 是否有使用监控
- [ ] 是否有侵权检测

#### 2. 知识产权保护

- [ ] 是否有模型水印
- [ ] 是否有使用授权
- [ ] 是否有侵权监控
- [ ] 是否有法律追诉机制
